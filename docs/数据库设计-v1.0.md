## 2. 设计原则

1. **一实体一表**，跨域引用只通过主键外键，不做冗余副本；域间只读引用写在接口层，不写跨域视图。
2. **主键**：业务主键用 `id BIGINT UNSIGNED AUTO_INCREMENT`，另设业务唯一键（学号、赛事编号等）。
3. **时间**：所有时间字段为 `DATETIME`，统一 Asia/Shanghai；创建/更新时间用 `created_at` / `updated_at` 并在应用层写入，不用数据库默认值（避免时区歧义）。
4. **软删除**：会员、题目、赛事、队伍四类主数据加 `deleted_at`，其余从表物理删除。
5. **状态字段**：一律 `VARCHAR(20)` + 注释列出取值，不用 `ENUM`（便于加值与迁移）。
6. **金额**：`DECIMAL(10,2)`，不用浮点。
7. **审计**：`audit_log` 单表记录关键写操作，含操作人、对象、前后值摘要。
8. **归档**：学年归档用 `academic_year` 字段 + `archived_at`，归档后只读由应用层控制，不加触发器。

## 4. 物理设计（DDL）

### 4.0 方言映射

本节 DDL 用 MySQL 8.0 语法书写，目的是把字段、类型宽度、约束与索引表达清楚。落地时按下表转换，**表名、字段名、唯一键、外键、索引一律不变**，只改类型写法。

| MySQL 8.0 | SQLite | 说明 |
|---|---|---|
| `BIGINT UNSIGNED AUTO_INCREMENT` | `INTEGER PRIMARY KEY AUTOINCREMENT` | SQLite 的 `INTEGER PRIMARY KEY` 即 rowid 别名，加 `AUTOINCREMENT` 保证 id 不复用 |
| `VARCHAR(n)` | `TEXT` | SQLite 不校验长度；长度约束改在应用层与 `CHECK` 里 |
| `DATETIME` | `TEXT`（ISO 8601，`YYYY-MM-DD HH:MM:SS`） | 时间比较用字符串字典序，格式必须统一 |
| `DATE` | `TEXT`（`YYYY-MM-DD`） | 同上 |
| `DECIMAL(10,2)` | `NUMERIC` | 综测分值、报名费；计算时在应用层用 `Decimal`，避免浮点误差 |
| `TINYINT(1)` | `INTEGER` + `CHECK (col IN (0,1))` | 布尔 |
| `JSON` | `TEXT` + `json_valid()` 检查 | `kp_snapshot` 等；SQLite 3.38+ 内置 JSON 函数 |
| `MEDIUMTEXT` | `TEXT` | 题面、题解 |
| `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='…'` | 删除 | 表注释改为 `--` 行注释或迁移脚本中的元数据表 |
| `UNIQUE KEY` / `KEY` / `FOREIGN KEY` | 同名子句，可保留 | 需在每个连接上执行 `PRAGMA foreign_keys=ON`，否则外键不生效 |
| 部分索引 `WHERE` 条件 | 支持 | SQLite 支持 partial index，`ON CONFLICT` 语义与 MySQL 的 `ON DUPLICATE KEY` 不同，需改写 |

三个落地时必须注意的点：

1. **外键默认不生效**。每个连接都要 `PRAGMA foreign_keys=ON`，连接池初始化时执行一次；漏掉就会出现“删了父记录、子记录还在”。
2. **写并发是库级的**。管理员批量导入与会员打卡同时发生会串行化；用 `PRAGMA journal_mode=WAL` 改善读并发，写仍然排队，超时设 5 秒并给出可读错误。
3. **时间统一存字符串**。不用 SQLite 的 `date()`/`datetime()` 隐式转换，时区问题在应用层解决。

升级到 PostgreSQL 时，把 `AUTOINCREMENT` 换回 `GENERATED BY DEFAULT AS IDENTITY`，`TEXT` 收窄为 `VARCHAR(n)`（可选），`NUMERIC` 保持，`JSON` 换 `JSONB` 并给 `kp_snapshot` 建 GIN 索引。


### 4.1 域 A 会员与协会

```sql
CREATE TABLE department (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  name          VARCHAR(50)  NOT NULL,
  type          VARCHAR(20)  NOT NULL COMMENT '技术/宣传/组织/其他',
  created_at    DATETIME     NOT NULL,
  updated_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_dept_name (name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='部门';

CREATE TABLE member (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  student_no    VARCHAR(20)  NOT NULL COMMENT '学号，业务唯一键',
  name          VARCHAR(50)  NOT NULL,
  major         VARCHAR(80)  NULL,
  grade         SMALLINT     NULL COMMENT '入学年份',
  phone         VARCHAR(20)  NULL,
  email         VARCHAR(120) NULL,
  photo_path    VARCHAR(255) NULL,
  member_type   VARCHAR(20)  NOT NULL COMMENT '观察会员/正式会员/实验室成员/管理会员',
  member_status VARCHAR(20)  NOT NULL COMMENT '报名中/待审核/观察会员/正式会员/竞赛实验室成员/已退会/已除名',
  dept_id       BIGINT UNSIGNED NULL,
  joined_on     DATE         NULL COMMENT '入会日期',
  left_on       DATE         NULL,
  created_at    DATETIME     NOT NULL,
  updated_at    DATETIME     NOT NULL,
  deleted_at    DATETIME     NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_member_student_no (student_no),
  KEY idx_member_status (member_status),
  KEY idx_member_dept (dept_id),
  CONSTRAINT fk_member_dept FOREIGN KEY (dept_id) REFERENCES department (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='会员';

CREATE TABLE member_assessment (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  member_id     BIGINT UNSIGNED NOT NULL,
  term          VARCHAR(20)  NOT NULL COMMENT '如 2026-2027-1',
  result        VARCHAR(20)  NOT NULL COMMENT '通过/不通过/待定',
  in_watchlist  TINYINT(1)   NOT NULL DEFAULT 0,
  assessed_at   DATETIME     NOT NULL,
  remark        VARCHAR(255) NULL,
  PRIMARY KEY (id),
  KEY idx_assess_member (member_id),
  KEY idx_assess_term (term),
  CONSTRAINT fk_assess_member FOREIGN KEY (member_id) REFERENCES member (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='考核记录';

CREATE TABLE member_award (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  member_id     BIGINT UNSIGNED NOT NULL,
  award_type    VARCHAR(20)  NOT NULL COMMENT '奖励/惩处',
  title         VARCHAR(100) NOT NULL COMMENT '如 优秀会员/警告',
  reason        VARCHAR(500) NULL,
  happened_on   DATE         NOT NULL,
  extra_points  DECIMAL(5,2) NULL COMMENT '综测加分，可为负',
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  KEY idx_award_member (member_id),
  CONSTRAINT fk_award_member FOREIGN KEY (member_id) REFERENCES member (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='奖惩记录';

CREATE TABLE permission_point (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  code          VARCHAR(60)  NOT NULL COMMENT '如 member:approve',
  module        VARCHAR(20)  NOT NULL COMMENT '域代号 A-F',
  description   VARCHAR(120) NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_perm_code (code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='权限点';

CREATE TABLE member_permission (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  member_id     BIGINT UNSIGNED NOT NULL,
  permission_id BIGINT UNSIGNED NOT NULL,
  granted_at    DATETIME     NOT NULL,
  granted_by    BIGINT UNSIGNED NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_member_perm (member_id, permission_id),
  CONSTRAINT fk_mp_member FOREIGN KEY (member_id) REFERENCES member (id),
  CONSTRAINT fk_mp_perm FOREIGN KEY (permission_id) REFERENCES permission_point (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='会员权限授予';
```

### 4.2 域 B 题库与训练

```sql
CREATE TABLE knowledge_point (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  parent_id     BIGINT UNSIGNED NULL,
  name          VARCHAR(80)  NOT NULL,
  difficulty    VARCHAR(20)  NOT NULL COMMENT '入门/提高/进阶/区域赛',
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  KEY idx_kp_parent (parent_id),
  CONSTRAINT fk_kp_parent FOREIGN KEY (parent_id) REFERENCES knowledge_point (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识点（树）';

CREATE TABLE problem (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  title         VARCHAR(200) NOT NULL,
  source        VARCHAR(100) NULL COMMENT '自建/Codeforces/Vjudge 等',
  external_id   VARCHAR(100) NULL COMMENT '外部 OJ 题目标识',
  platform      VARCHAR(40)  NULL COMMENT '外部平台名',
  difficulty    VARCHAR(20)  NOT NULL COMMENT '入门/提高/进阶/金银铜级',
  statement     MEDIUMTEXT   NULL,
  sample_in     MEDIUMTEXT   NULL,
  sample_out    MEDIUMTEXT   NULL,
  created_by    BIGINT UNSIGNED NULL,
  created_at    DATETIME     NOT NULL,
  updated_at    DATETIME     NOT NULL,
  deleted_at    DATETIME     NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_problem_external (platform, external_id),
  KEY idx_problem_difficulty (difficulty),
  CONSTRAINT fk_problem_creator FOREIGN KEY (created_by) REFERENCES member (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题目';

CREATE TABLE problem_kp (
  problem_id    BIGINT UNSIGNED NOT NULL,
  kp_id         BIGINT UNSIGNED NOT NULL,
  PRIMARY KEY (problem_id, kp_id),
  KEY idx_pk_kp (kp_id),
  CONSTRAINT fk_pk_problem FOREIGN KEY (problem_id) REFERENCES problem (id),
  CONSTRAINT fk_pk_kp FOREIGN KEY (kp_id) REFERENCES knowledge_point (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题目与知识点多对多';

CREATE TABLE problem_solution (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  problem_id    BIGINT UNSIGNED NOT NULL,
  author_id     BIGINT UNSIGNED NULL,
  content_md    MEDIUMTEXT   NOT NULL,
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  KEY idx_solution_problem (problem_id),
  CONSTRAINT fk_solution_problem FOREIGN KEY (problem_id) REFERENCES problem (id),
  CONSTRAINT fk_solution_author FOREIGN KEY (author_id) REFERENCES member (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题解';

CREATE TABLE training_plan (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  term          VARCHAR(20)  NOT NULL COMMENT '学期或假期，如 2026-2027-1 / 2027-winter',
  goal          VARCHAR(500) NULL,
  intensity     VARCHAR(20)  NULL COMMENT '低/中/高',
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_plan_term (term)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='训练计划';

CREATE TABLE training_phase (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  plan_id       BIGINT UNSIGNED NOT NULL,
  name          VARCHAR(40)  NOT NULL COMMENT '基础/强化/冲刺',
  start_on      DATE         NOT NULL,
  end_on        DATE         NOT NULL,
  PRIMARY KEY (id),
  KEY idx_phase_plan (plan_id),
  CONSTRAINT fk_phase_plan FOREIGN KEY (plan_id) REFERENCES training_plan (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='训练阶段';

CREATE TABLE training_task (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  phase_id      BIGINT UNSIGNED NOT NULL,
  title         VARCHAR(200) NOT NULL,
  assignee_type VARCHAR(20)  NOT NULL COMMENT '全体/观察会员/指定会员/指定队伍',
  deadline_at   DATETIME     NULL,
  created_by    BIGINT UNSIGNED NULL,
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  KEY idx_task_phase (phase_id),
  KEY idx_task_deadline (deadline_at),
  CONSTRAINT fk_task_phase FOREIGN KEY (phase_id) REFERENCES training_phase (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='训练任务';

CREATE TABLE task_problem (
  task_id       BIGINT UNSIGNED NOT NULL,
  problem_id    BIGINT UNSIGNED NOT NULL,
  sort_no       INT            NOT NULL DEFAULT 0,
  PRIMARY KEY (task_id, problem_id),
  KEY idx_tp_problem (problem_id),
  CONSTRAINT fk_tp_task FOREIGN KEY (task_id) REFERENCES training_task (id),
  CONSTRAINT fk_tp_problem FOREIGN KEY (problem_id) REFERENCES problem (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='任务题目关联';

CREATE TABLE checkin (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  task_id       BIGINT UNSIGNED NULL,
  member_id     BIGINT UNSIGNED NOT NULL,
  checkin_date  DATE         NOT NULL,
  minutes       INT          NULL COMMENT '训练时长',
  solved_count  INT          NULL,
  status        VARCHAR(20)  NOT NULL COMMENT '打卡/补卡/缺卡',
  source        VARCHAR(20)  NOT NULL COMMENT '手工/OJ同步',
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_checkin (member_id, task_id, checkin_date),
  KEY idx_checkin_date (checkin_date),
  CONSTRAINT fk_checkin_task FOREIGN KEY (task_id) REFERENCES training_task (id),
  CONSTRAINT fk_checkin_member FOREIGN KEY (member_id) REFERENCES member (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='打卡记录';

CREATE TABLE assessment_test (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  title         VARCHAR(120) NOT NULL,
  test_type     VARCHAR(20)  NOT NULL COMMENT '周测/月测',
  held_on       DATE         NOT NULL,
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  KEY idx_test_date (held_on)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='测评';

CREATE TABLE test_score (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  test_id       BIGINT UNSIGNED NOT NULL,
  member_id     BIGINT UNSIGNED NOT NULL,
  solved_count  INT          NULL,
  score         DECIMAL(6,2) NULL,
  kp_snapshot   JSON         NULL COMMENT '本次各知识点得分快照，用于能力曲线',
  PRIMARY KEY (id),
  UNIQUE KEY uk_score (test_id, member_id),
  CONSTRAINT fk_score_test FOREIGN KEY (test_id) REFERENCES assessment_test (id),
  CONSTRAINT fk_score_member FOREIGN KEY (member_id) REFERENCES member (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='测评成绩';
```

### 4.3 域 C 集训

```sql
CREATE TABLE camp (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  name          VARCHAR(80)  NOT NULL COMMENT '如 2027 寒假集训',
  period        VARCHAR(20)  NOT NULL COMMENT '寒假/暑假',

  camp_id       BIGINT UNSIGNED NOT NULL,
  member_id     BIGINT UNSIGNED NOT NULL,

CREATE TABLE camp_attendance (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  camp_id       BIGINT UNSIGNED NOT NULL,
  member_id     BIGINT UNSIGNED NOT NULL,
  att_date      DATE         NOT NULL,
  check_in_at   DATETIME     NULL,
  check_out_at  DATETIME     NULL,
  leave_type    VARCHAR(20)  NULL COMMENT '事假/病假/公假，NULL 表示未请假',
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_attendance (camp_id, member_id, att_date),
  KEY idx_att_date (att_date),
  CONSTRAINT fk_att_camp FOREIGN KEY (camp_id) REFERENCES camp (id),
  CONSTRAINT fk_att_member FOREIGN KEY (member_id) REFERENCES member (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='集训考勤';

CREATE TABLE multi_school_contest (
```

### 4.4 域 D 赛事

```sql
CREATE TABLE contest (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  name          VARCHAR(120) NOT NULL,
  contest_type  VARCHAR(20)  NOT NULL COMMENT '校赛/XCPC/非XCPC(蓝桥杯等)/校外',
  rule_note     VARCHAR(500) NULL COMMENT '赛制说明',
  quota         INT          NULL COMMENT '参赛名额',
  status        VARCHAR(20)  NOT NULL COMMENT '策划中/报名中/报名截止/进行中/已结束/已归档',
  signup_start  DATETIME     NULL,
  signup_end    DATETIME     NULL,
  held_on       DATE         NULL,
  created_at    DATETIME     NOT NULL,
  updated_at    DATETIME     NOT NULL,
  deleted_at    DATETIME     NULL,
  PRIMARY KEY (id),
  KEY idx_contest_type_status (contest_type, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='赛事';

CREATE TABLE contest_signup (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  contest_id    BIGINT UNSIGNED NOT NULL,
  team_id       BIGINT UNSIGNED NULL COMMENT '队伍报名时填',
  member_id     BIGINT UNSIGNED NULL COMMENT '个人报名时填',
  status        VARCHAR(20)  NOT NULL COMMENT '待审核/已通过/已拒绝/已退赛',
  fee           DECIMAL(10,2) NULL,
  fee_note      VARCHAR(200) NULL COMMENT '本期只记金额，不对接支付',
  applied_at    DATETIME     NOT NULL,
  created_at    DATETIME     NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_signup_contest_team (contest_id, team_id),
  KEY idx_signup_contest (contest_id),
  CONSTRAINT fk_signup_contest FOREIGN KEY (contest_id) REFERENCES contest (id),
  CONSTRAINT fk_signup_team FOREIGN KEY (team_id) REFERENCES team (id),
  CONSTRAINT fk_signup_member FOREIGN KEY (member_id) REFERENCES member (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='赛事报名';

CREATE TABLE contest_site (
  id            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  contest_id    BIGINT UNSIGNED NOT NULL,
  name          VARCHAR(100) NOT NULL,
  region        VARCHAR(60)  NULL,
  held_on       DATE         NULL,
```

## 5. 索引与约束说明

| 表 | 关键索引 | 理由 |
|---|---|---|
| `member` | `uk_member_student_no`、`idx_member_status`、`idx_member_dept` | 学号是业务唯一键；状态筛选用于观察名单与统计；部门用于分组报表 |
| `problem` | `uk_problem_external(platform, external_id)` | 外部 OJ 同步的幂等键，防止重复导入 |
| `checkin` | `uk_checkin(member_id, task_id, checkin_date)` | 同一人同一任务同一天只允许一条，打卡与 OJ 同步共用此约束做去重 |
| `camp_attendance` | `uk_attendance(camp_id, member_id, att_date)` | 同上，避免重复签到 |
| `contest_signup` | `uk_signup_contest_team` | 同一赛事同一队伍只报一次，防并发重复提交 |
| `test_score` / `team_rank` | 均按 (主体, 周期) 唯一 | 保证同一周期只有一份成绩或排名 |
| `audit_log` | 三元索引（actor / target / time） | 审计查询主要按人、按对象、按时间段 |

不加数据库触发器的理由：状态迁移合法性（如会员不能从「已除名」回到「正式会员」）在应用层统一校验，便于给出可读错误信息，也便于单元测试；跨表一致性用事务保证。

## 9. 容量与运维

- 三年 30 万行、单表最大 `checkin` 约 3 万行，索引全部可在内存中容纳；无需分区。
- 备份：每日全量 `mysqldump`（或 `pg_dump`）+ 每周一次整库快照，保留 8 周；学年归档后额外留一份只读副本。
- 归档：`academic_year` 归档后，报表查询默认只查当前学年，历史学年走归档副本，避免主表膨胀。
