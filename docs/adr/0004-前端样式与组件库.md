# ADR 0004：前端样式与组件库

- 状态：已接受
- 日期：2026-11-24
- 相关：ADR 0002、[issue #1](https://github.com/blrain3/ladder-up/issues/1)、[前端样式迁移评审](../review/ui-bootstrap5-review.md)

## 背景

ADR 0002 已选定 Jinja2 与 Bootstrap 5，但仓库此前实际分发 Bootstrap 3.2.0，模板也沿用了第三版的组件类名。Issue #1 跟踪这项偏差。本次迁移统一了模板、折叠导航、徽章和图标，并按评审补齐权限入口、可访问性、静态资产许可与回归测试。

## 决策

- 使用 Bootstrap 5.3.3 与 Bootstrap Icons 1.11.3。CSS、JS bundle（含 Popper）和图标字体全部由应用从 `/static` 本地托管，随应用部署并附对应许可证，无需访问 CDN。
- 延续 Jinja2 服务端渲染，放弃 SPA。会员、题库和训练页面以列表、详情和表单为主，服务端渲染可直接复用现有会话、权限和 CSRF 校验。打印、确认和录分等局部交互用原生 JavaScript，省去独立的前端构建、客户端路由及会话状态同步。
- 项目样式集中在 Bootstrap 后加载的 `app.css`，通用交互放在 `app.js`。
