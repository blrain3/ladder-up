## 必须修（10 条）

1. **整棵子树超深**（`app/taxonomy.py:57、82–96`）。把有孩子的根移到第 4 层下，根落第 5 层，孩子落第 6 层。改写前检查 `new_depth + max(row.depth - old_depth)`，超限返回 40002。
2. **并发可写出环或过期路径**（`app/routes.py:995–1019、1030–1046`）。SQLite 默认模式下，SELECT 未开启写事务。隔离库以两个会话先校验再依次提交，复现两个根互挂，外键允许两个有效 ID 互指。移动与建点应在首次读树前获取 `BEGIN IMMEDIATE`，随后重新读取父链和子树。
3. **并发冲突返回 500**（`app/routes.py:1001–1019、1034–1072、924–943`）。先查再写时，唯一索引或外键可在 flush/commit 拒绝操作。树删除应在写事务内检查叶子和引用，并处理约束异常。按约束回滚并返回冲突或引用错误。外部题唯一索引也覆盖软删行，预查须采用同一口径，或明确可重用且同步修改索引。
4. **知识点 HTML 页必崩**（`app/templates/knowledge_points.html:19、33`，`app/routes.py:855–859`）。Jinja 将 `tree.items` 解析成字典方法，实测迭代报 TypeError。两处改用 `tree["items"]`，并在列表序列化中带上难度，避免难度列为空。
5. **检索入口错配**（`app/templates/problems.html:12–14、115–119`，`app/routes.py:1130–1134、1156–1164`）。浏览器提交“全部”产生 `kp=`，整数校验返回 400。翻页又丢失筛选，文档参数 `kpId`、`problemType` 被忽略。统一参数并兼容现有名称，空知识点视为无筛选，分页链接保留条件。查询值统一去首尾空白，来源和关键词明确大小写规则，关键词按字面匹配转义通配符。
6. **录题丢关联且缺样例入口**（`app/routes.py:103–105、825–841、917–922`，`app/templates/problems.html:79–89`）。HTML 多选提交重复键，实测取到最后一个。表单用 `getlist` 保留多选与现有逗号输入。补样例字段，明确并执行 S05 的缺样例校验，录入后回读样例及全部关联。
7. **维护接口缺项**（`app/routes.py:983–1075、1188–1259`，`docs/接口设计-v1.0.md:113–117`）。知识点无名称或难度更新，题目无软删除，题解只有独立 POST，题目更新只有 POST。补文档约定的 PUT、DELETE 和题解 GET，保留表单入口，沿用鉴权与审计。
8. **链接解析错误使详情 500**（`app/markdown.py:13–19、24–30`，`app/routes.py:894、1256–1259`）。实测括号不匹配的 IPv6 URL 触发 `ValueError`。题解提交还会先提交数据库，再因渲染失败返回 500。解析失败时移除 href，写入前完成渲染校验，避免失败响应留下记录。
9. **代码示例显示错误**（`app/markdown.py:44–49`）。围栏代码再次转义，实测比较符和等号显示为实体拼写。配置渲染器禁用原始 HTML，或对渲染后的 HTML 做允许列表清洗，使代码由 Markdown 转义一次。回归检查代码文本和危险标签。
10. **统计漏项**（`app/routes.py:1081–1126`，`docs/接口设计-v1.0.md:118`）。内连接丢失零题量知识点，知识点关联数被加进使用频次，响应无正确率。使用外连接和有效题计数，按任务引用计算使用频次。提交数据依赖后续切片时，应明确统计字段的交付阶段和零提交口径。

## 核对结果

- 树（`app/taxonomy.py:49–58、85–104`，`app/routes.py:1044–1046、1059–1072`，`app/db.py:30、40–42`）。自身和任意深度后代均被拒，尾斜杠区分 `/1/` 与 `/12/`。移动整棵子树及审计只提交一次，失败关闭会话时回滚。删除先查子节点及关联，外键阻止并发孤儿。
- 检索（`app/routes.py:1137–1174`）。路径 LIKE 参数绑定。正常路径只有数字和斜杠，无需转义路径段中的通配符。按唯一 ID 倒序，同一数据集排序稳定。空结果和不存在的知识点均返回 200、`total=0`。
- 内容（`app/markdown.py:22–49`，`app/templates/problem.html:20、26、32、41`，`app/routes.py:879–896`）。原文先转义，原始 script、iframe、style 及 onerror 属性只作文本。href 只保留 HTTP(S)，javascript、data 被移除。题面和题解用 `|safe`，输入仅来自 render，样例由模板自动转义。Markdown 图片可加载外链，src 未经协议检查。
- 权限（`app/auth.py:17–21、48–78、111–136`，`app/routes.py:76–77、849、1085–1112、1137、1193`）。默认仅 coach、sys_admin 可写，member、dept_admin 可读。正常参数及有效 CSRF 下，越权返回 403 并提交审计，匿名读返回 401，无登录重定向。详情、检索、统计均排除软删题。
- 迁移（`alembic/versions/0004_knowledge_path.py:17–34、79–108`，`tests/test_migration.py:32–50`）。0004 在有旧业务数据的标准库中新建四表，根名经 COALESCE 参与唯一约束，空表建索引无历史重名风险。已有同名表会在建表时报错。回填在正常升级为空操作。路径含自增 ID，同层多行不会相撞。若将回填复用于旧树，父路径为空也能推进，可能漏祖先。移除死回填，或以父路径已完成为条件并预检重名、环和深度。降级依次移除索引和子表，删除四张 S3 表及其数据。
