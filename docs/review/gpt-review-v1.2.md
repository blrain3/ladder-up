# 拾阶第三轮放行核对 v1.2

以第二轮评审 §三的三项最小阻塞为准。下文使用文件简称，基线为 v1.2，其余设计与计划为 v1.0。运行验收未核对，仓库 Makefile 目前只有文档、出图等目标，应用与测试目录仅有占位说明。

## 一、三项阻塞逐条判定

| 阻塞 | 判定 | 证据与实现影响 | 关闭条件 |
|---|---|---|---|
| S1 会话与授权 | 部分关闭 | 《接口设计》§2 按已登录表单、已登录 JSON、匿名申请分别选隐藏字段、请求头、双提交 Cookie，但又要求所有写操作绑定会话。§4.1 的公开登录无初始令牌规则，§5 的匿名 JSON 申请缺隐藏字段，ADR 0003 §1 仍统一选表单字段。双提交已定义 Cookie 和相等校验，签发入口、作用域及失败处理待定，匿名失败无会话可清。§2、§4.1 已定会话 Cookie 的 Path=/、退出 204 并清 Cookie、改密等撤销全部会话，《开发路线》S1 已要求旧 Cookie 返回 40101，清除属性和改密响应待定。《数据库设计》§4.1、§8 已落四种 role 和两段权限码，按授权表校验，但缺角色默认授权清单及本人、部门范围规则，《设计说明书》§7 的部门可读也尚未转成判定条件。《开发路线》S1 列匿名、跨会员和改密三项，匿名真实提交依赖 S2 才交付的申请页和表。 | 冻结登录与申请的匿名流程及各载体适用条件，明确撤销响应、种子权限和对象范围，将真实申请烟测放到 S2。 |
| 首批迁移与启动入口 | 部分关闭 | 《数据库设计》§4.0 与 ADR 0003 §3 均要求将 KEY 改写为独立索引。《开发路线》S1 明列 attachment 同批建表，但《项目计划》§4 仍排入 S2，按后者会让首批照片外键引用尚未迁移的表。《接口设计》§2、§4.7 可推出 /api/v1/health，路线 S1 和设计 §9 使用 /health；路线测容器内 8000、称对外只开 443，设计 §9 发布 443/80，代理 HTTPS 烟测无明确命令。设计 §6、§9 用 app 容器跑作业，ADR §4 仍指向 cli 服务。接口 §3 已明确写锁超时为 HTTP 503、业务码 50301、Retry-After: 1，与 ADR §2 一致。 | 统一首批清单、健康路径及 80 用途，补代理侧烟测，定稿 Compose 作业服务和命令。 |
| 23 项验收排期 | 部分关闭 | 《项目计划》§3 的 M1 与路线 S2 的 11/30 对齐，M2 包含 S4 并到 12/07，但计划 §3、§5 将逐题打卡或 S4 完成放至第三周，路线 S4 已要求 12/07 完成。S7 已纳入第三周 12–14 小时合计，未分配可核对的独立工时，M3 退出条件仍缺双平台验证。计划 §4 要求签核裁剪并同步 §8，但 §8 仍硬性要求 23 项和双平台，且先砍 S7 又单列其 B-14，并列出本期只有 CSV 的导出替代格式（接口 §4.2）。NF-05 已进入路线 S4、测试 §6，计划 §8 仍只列 NF-01–03，测试 §5 的每次迁移回归在 S4 前缺打卡依赖。恢复已排 S5 首验、M4 回归（路线 §1、§4），但 S5 仅验库和登录，设计 §8 还要求抽验附件及导出，档案导出在 S6。 | 对齐周退出条件和工时，明确签核后的交付判定，定稿 NF-05 与恢复的分阶段门槛。 |

## 二、残留一致性抽查

| 抽查 | 证据与影响 |
|---|---|
| 表数与容量 | 《数据库设计》§3、§4 实点 38 个建表语句，表名对应一期 27、二期 11，基线 §11 一致。§3.1 相加 483,480 行，§3.3 写约 48 万，§9 仍写 47 万。README 文档表写 27 张完整 DDL。现有 PDF 经 pdfinfo 核对为 12 份、126 页，逐份与表列页数一致。 |
| 申请、照片与审计字段 | 接口 §4.2 的面试时间、备注和照片引用都有对应列（库 §4.1、§4.7），库 §4.6 的 request_id 对应设计 §6。库 §5 的活跃唯一键支持终态后重申，接口 §5 却笼统称学号重复即拒绝，可能误拒历史终态申请；录取端点也只在审核行间接出现。 |
| 异步响应 | 接口 §4.3 返回 taskId，§6 返回 jobRunId，同一轮询路径可导出两种客户端解析。库 §4.7 的日唯一键支持同日复用一行，响应应固定一个字段名。 |
| 场景与入口 | 测试 S06 与路线 S4 对齐定向和逐题落表，接口 §5 的完成数已可复算。S07 只安排一次限流后恢复，却要求记录失败原因，路线 S7 要求重试三次并留痕。应分别验证恢复成功与耗尽失败。 |
| 备份与归档 | 基线 §9 写年度全量，设计 §8 要每日并在升级前备份，需明确年度归档与运行备份。库 §2 按学年字段锁定，§9 改按创建时间导出，设计 §6 仍要求学年控制记录与版本，三处会导出不同的锁定范围。 |

## 三、放行结论

**不可开工。** 成本为开工前修订和交叉核对的人工估算。

| 最小阻塞 | 修法 | 成本 |
|---|---|---|
| 鉴权与首轮烟测 | 同步接口 §2、§4.1、§5 与 ADR §1，确定匿名签发和提交格式、退出与撤销响应。按库 §8 列角色默认授权与对象范围，路线 S1 测登录、越权和撤销，S2 测申请令牌缺失及不匹配。 | 2–3 小时 |
| 迁移与启动 | 同步计划 §4 与路线 S1 的附件批次，固定接口 §4.7 的绝对健康路径、部署 §9 的代理入口与 ADR §4 的作业命令，验收写锁错误码及重试头。 | 1–2 小时 |
| 排期与签核 | 对齐计划 §3–5、§8、路线 §1、§4 和测试 §5–6，单列 S7 工时及双平台退出条件。裁剪时签核更新基线、矩阵及完成口径。S4 首验 NF-05、其后迁移回归，S5 首验隔离恢复，S6 补导出抽验，M4 留完整回归记录。 | 2–3 小时 |
