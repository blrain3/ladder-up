## 必须修（10 条）

1. **照片越权。** `app/routes.py:230–266,284–290`、`app/auth.py:17–20`。部门管理员的默认权限可跨部门下载、替换和删除照片。对附件所属会员及照片写入目标共用部门范围校验，跨部门走带审计的 403，补同部门与跨部门读写测试。
2. **上传上限与图片完整性。** `app/storage.py:14–19,41–49`、`tests/test_attachment.py:25–30,55–61`。超限测试只看错误码，整文件先读仍能通过。成功夹具仅有 PNG 签名和零字节填充。限制 multipart 接收总量，分块计数，超限即停止，使用真实图片并验证可解码。
3. **照片失败后遗留文件。** `app/routes.py:235–249`、`app/storage.py:53–65`。会话查询后做文件 IO，磁盘写入先于数据库提交，flush 或 commit 报错会留下无主文件。事务外限量写临时文件并核验大小和摘要，短事务登记并切换引用，为失败清理及中断恢复建立测试。
4. **录取账号使用共享密码。** `app/routes.py:87–102,601–610`、`app/models/member.py:34`。所有新录取者共用演示值或固定回退值，登录未执行首次改密标记。改为逐账号一次性激活，完成设密前限制会话能力。种子默认管理员密码也应只允许在明确的演示模式使用（`bin/seed.py:70–83`）。
5. **已有会员状态被覆盖。** `app/routes.py:602–620`。既有正式、退会、除名及软删除会员都进入同一分支，仅覆盖状态并保留原类型、权限、离会及删除标记。拒绝既有会员录取或实现显式恢复规则，分别验证退会、除名及活跃会员。
6. **状态迁移存在竞态。** `app/routes.py:548–566,578–595,631–655`。先读状态后按主键写入，并发审核可覆盖拒绝并留下 NULL 活跃标记。按预期状态和入会类型做条件更新，影响零行返 40002。面试不通过也应写面试时间并保留拒绝原因。
7. **后台 HTML 无法使用。** `app/templates/applications.html:26` 把字典的 items 方法当列表，临时测试确认渲染抛 TypeError。改用下标访问，增加含实际申请行与操作表单的 HTML 断言；`tests/test_review.py:26–50` 的 JSON 流程对此仍会全绿。
8. **匿名进度查询暴露申请状态。** `app/routes.py:444–454,475–490`。冲突响应提供已有编号，查询仅凭该编号和学号即可读取状态。保留业务冲突响应，进度页改用独立不可预测凭证或身份验证。
9. **输入越界变成 500。** `app/routes.py:390–397,476–485,638–645`。超长数字年份可在 int 转换时报错，查询编号和部门 ID 缺 SQLite 整数上限。先限制数字长度及范围，畸形参数统一返 40001。
10. **录取烟测可假绿。** `scripts/smoke.sh:122–143` 查种子 demo0001 的证，录取的是另一学号；`json_field` 处理 JSON null 会打印 None，现有比较仍通过。核对实际录取 ID、学号、状态及回填，用同一身份验卡，并覆盖照片上传与非图片拒绝。

## 建议修

- `app/routes.py:514–539`、`docs/接口设计-v1.0.md:91,191`。申请列表只有后台路径且要求 approve，通用 POST /files 未实现。对齐 S2 对外清单，明确列表的 read 权限和对象范围，以及通用上传归属切片。
- `tests/test_seed_passwords.py:8–10` 仅断言日志不含 bcrypt 前缀，输出明文仍能通过。断言日志不含两个夹具密码。补审核、面试与拒绝审计的 actor、request_id 及目标断言（`tests/test_review.py:62,80–88`）。权限失败目前用权限点前缀作为对象类型，申请编号因此记成会员编号。应传入明确的申请对象类型，便于按对象追溯越权事件（`app/auth.py:118–125`）。
- `alembic/versions/0003_member_application_attachment.py:24–41`。补缺列分支只有新增 active_flag 时建索引，也未回填旧活跃申请，降级不移除这些补列。若支持偏离标准 0002 的库，独立检查索引并定义回填与降级策略。
